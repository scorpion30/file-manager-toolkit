      How to use Add Page Numbers

      1. Select your PDFs, or a folder.
      2. Choose where the number goes and how it reads, like "Page 1 of 10".
      3. Add the numbers and download.

      Questions

      Can I skip the cover page?

      Yes. Tick "Skip the first page", or type the pages to number, like 2- for page 2 to the end. Set the first number to choose where counting starts.

      What is Bates numbering?

      One running number across a whole set of documents, with a prefix, such as DOC-000001 to DOC-000250. It is used for legal and contract documents and for document control.

      Can I number many PDFs at once?

      Yes. Select as many files as you like, or a whole folder. Each file gets its own numbers, or one running number with Bates numbering.

PDF to Excel

Draw boxes on one PDF, then read the text in the same boxes from all your PDFs into Excel.

1 · PDF files

    Click a file to show it on the right. Drop PDFs anywhere on this page.

    2 · Areas to read

      Each area becomes a column in Excel. Rename the column here. Zoom with the mouse wheel.

      3 · Read the text

      Real PDF text is read directly. If an area has no text (scanned or outlined), OCR is used.

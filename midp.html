MIDP Check

Check every file in a submission against the MIDP and the TIDPs of all disciplines.

Your files stay on your computer. Nothing is uploaded.

Deliverables lists

Add the MIDP, or one TIDP per discipline. For each file, pick the column that holds the document number (the file name each deliverable should have).

No MIDP yet? Skip this step and check only the file names.

Received files

Choose the submission folder. You can add one folder per discipline. Every file type counts: PDF, DWG, RVT, IFC, NWC, DOCX, XLSX…

    Naming rule (optional)

    Check every file name field by field, for example ISO 19650 names like PRJ-ORG-VOL-LVL-TYP-ROL-NUM. Let the tool learn the rule from the received files, or type one correct name, then adjust each field.

    FieldExampleCharactersTypeFixed value(s)Found in the files

    Characters: one number (3) or a range (3-5), empty = any length. Fixed value(s): leave empty if the field changes from file to file, or list the allowed values separated by commas.
